# Interactive Personal Budget Manager — Release 1

Python I | Session 10 | Practice 1

Record income and expenses, list transactions, and calculate balances by currency.
Transactions are stored in CSV and automatically loaded on subsequent runs.

## Setup and run

Requires Python 3.9+ (standard library only). Clone or extract the project, then
open a terminal in its root directory. With uv installed, use:

```powershell
uv run --no-project budget.py --help
```

Alternatively, use `python budget.py --help` (or `py budget.py --help` on
Windows). In all examples below, replace `uv run --no-project budget.py` with
`python budget.py` if using a standalone Python installation.

### Example

Run the following with a fresh data file:

```powershell
uv run --no-project budget.py add 100 --kind income --category salary --date 2026-09-01
uv run --no-project budget.py add 18.50 --category food --date 2026-09-04
uv run --no-project budget.py list
uv run --no-project budget.py summary
```

Expected summary: income 100.00 EUR, expenses 18.50 EUR, balance 81.50 EUR.
The default kind is `expense`, currency is `EUR`, and date is today's local date.
Successful additions create or update `data/transactions.csv`. Repeating an
addition creates another record.

### Additional commands

```powershell
uv run --no-project budget.py list --month 2026-09 --category food
uv run --no-project budget.py summary --month 2026-09
uv run --no-project budget.py backup
uv run --no-project budget.py undo
```

`backup` creates a verified, timestamped CSV in `backups/`; an optional explicit
path must not already exist. `undo` removes the last added record, regardless of
its date, and saves the updated file. Both commands operate on the selected data file.

## Data and validation

Each transaction has six fields:

| Field | Rule |
| --- | --- |
| id | Unique identifier, e.g. T001; generated by the application |
| date | Valid ISO date (YYYY-MM-DD) |
| kind | `expense` or `income` |
| category | Controlled vocabulary, depending on kind |
| amount | Positive finite float, at most two decimal places, maximum 1,000,000,000 |
| currency | EUR, USD or GBP |

Expense categories: `food`, `housing`, `transport`, `utilities`, `health`,
`education`, `entertainment`, `other`.

Income categories: `salary`, `freelance`, `gift`, `other`.

Whitespace and case are normalized where appropriate. Invalid data is rejected;
CSV import errors identify the row. The CLI returns 0 on success, 2 for invalid
input/data and 1 for file-system errors. Errors go to stderr.

### Sample data

Use `--file` before the command to inspect the included examples without changing
personal transactions:

```powershell
uv run --no-project budget.py --file data/sample_transactions.csv summary --month 2026-09
uv run --no-project budget.py --file data/sample_invalid_transactions.csv list
```

The first command reports balances of 856.50 EUR and 90.00 USD separately.
The second rejects the file at row 3 (negative amount). A further invalid
category on row 4 can be tested after correcting row 3 in a copy of that file.

## Known limitations

- Single-user, sequential execution; no file locking, encryption or authentication.
- Fixed categories and supported currencies; no exchange-rate conversion.
- Float amounts follow the assignment schema; reports use Decimal arithmetic.
- Undo removes the last record only; IDs may be reused. There is no audit trail.
- Temporary-file replacement reduces partial-write risk but does not guarantee
  full power-loss durability. Backups are manual or externally scheduled, without
  automatic retention, retries or alerts.
- No editing, graphical interface or bank integration in Release 1.

Generated transactions, default backups and Python caches are excluded from Git.
